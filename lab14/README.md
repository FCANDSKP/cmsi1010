# Lab 14: Alien Invasion

In this lab, we learn how to animate. 

We start by painting the scene, with a re-emphasis on naming everything for clarity as learned in the previous lab. 

To make the UFO's we need to make them as a class since they are complicated shapes and we are going to have multiple UFO's. Inside class UFO, we set our default x and y positions to the width of 100 and the height of 30. 

For the animation, we need to draw our UFO's in slightly different places in successive frames. We change the code a little in order to be able to add different speed values to each UFO. Then, we need to control our framerate to make it less choppy.
